# Seasonal Spark

This is a browser extension that enhances the user's browsing experience with seasonal visual effects, uplifting tips, and micro-conversations. It adapts to the current season and offers a cozy, playful, or mindful vibe depending on user preferences.

## Getting Started

1.  Open your browser's extension page (e.g., `chrome://extensions`).
2.  Enable "Developer mode".
3.  Click "Load unpacked" and select the `seasonal-spark-extension` directory.
